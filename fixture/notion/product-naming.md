# Internal Product Naming Reference (Notion)
_Last updated: 2026-02-02 · Owner: Product Ops_

This page exists because new hires keep getting confused. Here is the canonical mapping between what customers see, what engineering says, and what billing charges.

## Core platform

| Context | Name used |
|---|---|
| Marketing / sales decks | **Meridian Pulse** |
| Engineering (Notion / Slack / Jira) | **Project Fathom** (original codename, still in daily use) |
| Billing system | **SKU-10045-ENT** — line item "Pulse Enterprise v3" |
| Support / Zendesk tags | "Pulse Enterprise" or sometimes just "Enterprise" |

> They are all the **same product**. Do not treat "Project Fathom" as a separate offering.

## Add-on module

| Context | Name used |
|---|---|
| Marketing | **Meridian Insights Add-on** |
| Engineering | **Project Lighthouse** |
| Billing system | **SKU-20087-ADD** |
| Slack / eng docs | "Insights Module (beta)" |

> ⚠️ Known inconsistency: the module is still tagged **(beta)** internally even though it went **GA and has been billed since Q3 2025**. The "beta" label is stale. Same product regardless of label.
